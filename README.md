Day Tracker

Overview

Day Tracker is a productivity application created as my final project for my first programming course. The program helps users organize tasks based on priority and available time throughout the day.

Features

* Input wake-up and sleep times
* Add High, Medium, and Low priority tasks
* Estimate task completion times
* Calculate available time in a day
* Determine whether tasks fit within the user's schedule
* Generate a summary file of tasks and results
* Hidden brainrot Easter egg

 How It Works

1. Enter your wake-up and sleep times.
2. Add tasks and assign each one a priority level.
3. Estimate how long each task will take.
4. The program calculates your available time.
5. A summary file is generated showing task priorities, estimated durations, and whether the tasks can be completed within the available timeframe.
